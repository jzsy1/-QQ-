## 三、协议端（NapCat）启动与扫码

协议端负责保持 QQ 在线，并将收到的聊天消息通过 OneBot v11 协议转发给 QQ 大脑。您可以根据运行环境在 **Linux 版** 或 **Windows 版** 中二选一：

### 1. Linux 版一键整合启动（方案 2 原生无头，单窗口全自动）

已将 **Linux NapCat 扫码客户端**、**QQ 大脑核心服务** 与 **Web 调控后台** 同样深度整合，**无需打开两次或手动开启第二个窗口**：

- **如果在 Windows 主机操作**：
  直接双击根目录下的：
  ```bat
  start_napcat_linux.bat
  ```
- **如果在 WSL Ubuntu 终端操作**：
  ```bash
  ./start_napcat_linux.sh
  ```
  *(注：同样支持传参快速登录指定账号，如：`./start_napcat_linux.sh -q <QQ号>`)*
- **扫码与自动联动**：
  1. 窗口启动后会自动启动 QQ 大脑核心服务与 Web 调控后台（`http://127.0.0.1:18888`）。
  2. 控制台直接输出 **ASCII 文本二维码**（同时生成图片 `/root/Napcat/opt/QQ/resources/app/app_launcher/napcat/cache/qrcode.png`）。
  3. 手机 QQ 扫码确认后，Linux NapCat 开启服务，大脑在同个终端中**自动秒级无缝通信上线**！
  4. 按 `Ctrl+C` 即可一键安全停止全部服务。
- **NapCat WebUI 管理面板**：
  - 网址：`http://127.0.0.1:6099/webui?token=005c27c5c4f7`
  - 可视化查看登录账号状态、心跳及网络通道。

---

### 2. Windows 版一键整合启动（推荐，单窗口全自动）

已将 **NapCat 扫码客户端**、**QQ 大脑核心服务** 与 **Web 调控后台** 深度整合！只需双击一个脚本，**无需打开两次或手动开启第二个窗口**：

- **启动方式**：
  直接双击根目录下的：
  ```bat
  start_napcat_windows.bat
  ```
  *(注：如需快速登录历史账号，也可带参运行，如：`start_napcat_windows.bat -q <QQ号>`)*
- **扫码与自动联动**：
  1. 窗口启动后会自动加载 QQ 大脑服务与 Web 调控后台（`http://127.0.0.1:18888`）。
  2. 控制台直接显示 NapCat 扫码二维码（若已有已登录账号可直接数字选择或自动登录）。
  3. 手机 QQ 扫码确认后，NapCat 启动 `ws://127.0.0.1:3001`，大脑在同个窗口中**自动秒级无缝对接**并打印上线日志！
  4. 按 `Ctrl+C` 可同时安全关闭大脑与 NapCat 进程。
- **NapCat WebUI 管理面板**：
  - 网址：`http://127.0.0.1:6099/webui?token=005c27c5c4f7`

## 四、QQ 大脑独立启动（分离模式，可选）

如果您希望 NapCat 与 QQ 大脑在不同终端分别运行，也可以使用分离模式：

### 1. 先启动协议端
- Linux：运行 `start_napcat_linux.bat` 或 `start_napcat_linux.sh`
- Windows：仅运行 `NapCat.Shell.Windows.Node\napcat.bat`

### 2. 再启动 QQ 大脑
- Windows 环境：
  ```powershell
  python run_qq.py
  ```
- Ubuntu / Linux 环境：
  ```bash
  python3 run_qq.py
  ```

## 五、Web 后台管理与在线调控

QQ 大脑启动时，会随同在后台开启 Web 调控面板：

- **访问地址**：`http://127.0.0.1:18888`
- **主要调控功能**：

### 1. 模型即时切换与参数调节
- **预设模型一键切换**：支持在 DeepSeek、本地 Gemma、通义千问、Google Gemini 等配置间无缝切换，无需重启大脑。
- **自定义模型参数**：在线调整 API Key、Base URL、Model Name、超时时间及上下文长度。

### 2. 人设与系统提示词热修改
- 可直接在网页端输入或调整机器人的专属人设、性格设定、回复规范和禁止事项。
- 保存后立即生效于下一轮对话生成。

### 3. 实时连接与运行状态
- 实时显示与 NapCat WebSocket 的连接心跳、总接收事件数、成功处理消息数与错误日志。

### 4. 身份管理与人工绑定
- 查看原生 QQ 用户的独立身份记录。
- 支持在明确人工授权的情况下，将特定平台用户进行身份安全绑定，彻底杜绝数据自动串号。

## 六、实测与功能验证指南

完成两端启动后，可以通过以下步骤进行全链路实测：

### 1. 基础对话测试（私聊 / 群聊）
- **私聊**：向已登录的机器人 QQ 发送任一消息，例如：
  > “你好，请问你是谁？”
  - 验证点：大脑收到消息并通过当前配置的模型生成自然回复。
- **群聊唤醒**：在机器人所在群中 @机器人 或输入配置的唤醒词（如 `小金鱼`）：
  > “@机器人 今天有什么新闻？”
  - 验证点：仅在被 @ 或命中唤醒词时触发回复，不乱插话。

### 2. 连续上下文与记忆测试
- **第 1 轮**：私聊发送 `“我最喜欢吃的水果是芒果，请记住哦。”`
- **第 2 轮**：发送无关话题 `“今天天气怎么样？”`
- **第 3 轮**：测试记忆检索 `“你还记得我最喜欢吃什么水果吗？”`
  - 验证点：回复明确包含“芒果”，控制台日志显示检索到记忆片段。

### 3. 主人指令与权限验证
- 使用配置在 `super_users` / `owner_qqs`（如 `10001`）的账号发送：
  > `状态`
  - 验证点：返回系统健康度、已运行时间、当前活动模型与记忆状态。

### 4. 点歌与音乐分享测试
- **发送**：
  > “我要听晴天” 或 “点歌 周杰伦 稻香” 或 “来首海阔天空”
  - **验证点**：
    1. 机器人默认优先检索 **QQ 音乐** 原生曲库（与 QQ 客户端生态无缝打通），若无版权则自动回退网易云。
    2. 向聊天窗口投递一张精致的 **QQ 音乐原生播放卡片**。
    3. 卡片发送成功后**不再额外发送冗余的文字链接**，保持聊天界面整洁清爽；仅当客户端卡片被风控时，才自动降级发送备用试听链接。
- **纯指令发送**：
  > “点歌” 或 “我要听歌”
  - **验证点**：机器人体贴引导：“想听什么歌呢？请告诉我歌名哦，例如：我要听 晴天 / 点歌 七里香 🎵”。

### 5. 实时天气查询测试
- **发送**：
  > “北京天气” 或 “上海天气怎么样” 或 “查一下深圳的天气预报” 或 “明天成都下雨吗”
  - **验证点**：
    1. 机器人通过全球高精度气象服务实时拉取气象数据。
    2. 包含气温、体感、天气现象、风向风级、相对湿度与温馨穿衣出行建议。

### 6. 情绪动力学与即时记忆迭代实测
- **情绪连续性（惯性动量）实测**：
  - **赞美/撒娇**：发送 `“小鱼鱼你好可爱呀，好喜欢你！么么哒”`
    - 大脑内在愉悦度（Valence）与激活度（Arousal）上升，进入甜美轻快心境，语气温柔亲昵；
  - **小挑衅/批评**：紧接着发送 `“你有点笨哦”`
    - 因情绪动量公式阻尼机制（$\lambda = 0.75$），不会瞬间崩塌变脸，而是表现出可爱的**小傲娇、撅嘴微嗔**（“哼，我才不笨呢”）；
  - **情绪与表情包联动**：情绪倾向会自动映射到表情挑选器，顺势发送同频动图（如傲娇、撒娇、高兴或委屈动图）。
- **即时事实提炼（事件驱动记忆）实测**：
  - 发送带有个人事实的对话，如：`“我平时在上海工作，业余最喜欢打羽毛球”`；
  - 大脑在后台异步完成事实提炼并自动入库写入 Profile，不再需要等待 30 分钟后台轮询。再次提问个人喜好时即刻生效！
    2. 回复包含：当前天气、实时气温、当日最高/最低温、风力风速。
    3. 根据温度与阴晴降水自动生成贴心出行穿衣建议（如雨雪提醒带伞、降温提醒保暖）。
- **纯指令发送**：
  > “查天气”
  - **验证点**：机器人友好询问：“你想查询哪个城市的天气呢？例如发送：北京天气 / 查上海天气 🌤️”。

## 七、常见问题与排查手册

### Q1: NapCat 扫码提示“二维码已过期”或网络超时？
- **原因**：腾讯二维码有效期约为 1-2 分钟。
- **解决方法**：直接重启 NapCat 脚本，会自动刷新最新的二维码供扫码。

### Q2: run_qq.py 提示 `OneBot 连接失败：连接被拒绝`？
- **原因**：NapCat 尚未启动，或 3001 端口尚未处于监听状态。
- **排查**：
  1. 确认 NapCat 窗口中显示已登录成功。
  2. 检查 NapCat 中 `onebot11.json` 是否包含正向 WebSocket 服务（监听 `3001` 端口）。

### Q3: 终端显示二维码变形排版混乱？
- **解决方法**：
  - 将终端字体切换为等宽字体（如 Consolas / Cascadia Mono / Ubuntu Mono）。
  - 或者直接打开 NapCat 自动生成的二维码图片：
    - Linux：`/root/Napcat/opt/QQ/resources/app/app_launcher/napcat/cache/qrcode.png`
    - Windows：`NapCat.Shell.Windows.Node/napcat/cache/qrcode.png`
  - 也可以登录 WebUI（`http://127.0.0.1:6099`）扫码。

### Q4: 如何在后台常驻运行 Linux 版 NapCat？
NapCat Linux Shell 版支持使用 `screen` 在后台常驻运行：
```bash
# 启动后台会话
screen -dmS napcat xvfb-run -a /root/Napcat/opt/QQ/qq --no-sandbox

# 重新回到该会话查看日志
screen -r napcat

# 退出查看但保持后台运行：按键盘 Ctrl+A 后按 D
```
