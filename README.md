## 一、架构说明与解耦特性

整个系统已完成**全量宿主系统剥离**（移除了 50+ 个宿主脚本、14 个旧功能目录、以及 18 块不相干的旧配置），形成一个 100% 独立自洽的轻量化 QQ 大脑：

```
                    ┌────────────────────────┐
                    │      手机 QQ 客户端    │
                    └───────────┬────────────┘
                                │ 腾讯 QQNT 协议
                    ┌───────────▼────────────┐
                    │  NapCat OneBot v11 端  │
                    │ (Windows / Linux Shell)│
                    └───────────┬────────────┘
                                │ 本地正向 WS (ws://127.0.0.1:3001)
                                │ 零外网暴露，极速本地 IPC
                    ┌───────────▼────────────┐
                    │      QQ 大脑服务       │
                    │     (run_qq.py)        │
                    ├────────────────────────┤
                    │ • 独立命名空间记忆 (qq)│
                    │ • 情绪动力学引擎 (PAD) │
                    │ • 独立轻量 SimpleBrain │
                    │ • 文本唤醒词 + @ 双唤醒 │
                    │ • 多模态视觉理解 (Vision)│
                    │ • 表情包 / 音乐卡片 / 天气│
                    └───────────┬────────────┘
                                │ 本地 HTTP (端口 18888)
                    ┌───────────▼────────────┐
                    │   Web 管理调控后台     │
                    │ (模型/人设/状态/身份)  │
                    └────────────────────────┘
```

- **零外部强依赖**：不依赖老系统的主控进程（Kekesi/抖音直播/桌面GUI工具全已剥离）。
- **极简独立通用库**：仅依托 `skills/kekesi_common/` 下的无外部依赖轻量库（`SimpleBrain`、`CompanionMemory` 等）。
- **完全记忆隔离**：QQ 用户记忆严格写入 `skills/im/qq/memory/` 独立数据库，不与任何外部系统串号。
- **纯净本地通信**：NapCat 与 QQ 大脑之间通过本地回环 `ws://127.0.0.1:3001` 通信，无需第三方代理。

## 三、核心配置文件详解 (config.yaml)

配置文件结构清爽，只分为 4 个部分：

```yaml
# 1. 核心大模型 (支持 DeepSeek / 硅基流动 / OpenAI 等兼容接口)
brain:
  profiles: {}
  active: ''
  provider: openai
  base_url: #api地址
  model: #模型
  api_key: #密钥sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
  timeout_sec: 60

# 2. 向量嵌入模型 (用于长期记忆语义检索，可选)
embedding:
  enabled: false
  model: #模型
  base_url:  #api地址
  api_key: #密钥sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
  timeout_sec: 10

# 3. Web 后台管理设置
admin:
  token: ''

# 4. QQ 机器人服务核心配置
qq:
  enabled: true
  ws_url: ws://127.0.0.1:3001  # NapCat OneBot 协议端通信地址
  access_token: ''
  reconnect_sec: 5

  # 白名单（为空表示允许所有私聊 / 所有群聊）
  groups: []
  privates: []

  # 权限控制
  super_users: ['']  # 超级管理员 QQ
  owner_qqs: ['']    # 主人 QQ（群聊免唤醒、专属称呼特权）

  # 人设与唤醒词
  agent_id: YY
  wake_words: ['鱼鱼', '小金鱼'] # 群聊文本唤醒词
  owner_names: ['鱼片', '主人']  # 对主人的专属称呼
  system_prompt: '...'         # 自定义人设系统提示词

  # 流控与防刷屏
  wake_window_sec: 120         # 唤醒后保持连续对话时长（秒）
  batch_ms: 3000               # 攒批延迟（毫秒），避免一句话分几段发时频繁打字
  batch_size: 3                # 单次回复聚合的消息条数
  max_reply_chars: 120         # 回复最大字数
  history_turns: 4             # 滚动上下文轮数

  # 视觉多模态看图理解
  vision_enabled: true
  vision_model: #模型
  vision_base_url: #api地址
  vision_api_key: #密钥sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

## 四、一键启动与扫码指南

### 1. Windows 版启动（推荐，单窗口全自动）
只需双击根目录下的：
```bat
start_napcat_windows.bat
```
- **窗口特性**：
  1. 脚本内置防闪退保护与 `CRLF` 编码保护；
  2. 自动启动 **QQ 大脑**、**Web 后台**，并拉起 **NapCat 扫码界面**；
  3. 控制台会直接显示二维码字符，也可打开图片 `NapCat.Shell.Windows.Node/napcat/cache/qrcode.png` 扫码；
  4. 手机 QQ 确认登录后，大脑自动建立本地 WS 桥接，无需手动打开第二个窗口！
  5. 按 `Ctrl+C` 可一键同时安全关闭大脑与 NapCat。

### 2. Linux / WSL 版启动（无头全自动）
- **如果在 Windows 唤起 WSL**：双击 `start_napcat_linux.bat`
- **如果在 Linux / WSL 终端操作**：运行 `./start_napcat_linux.sh`

### 3. 分离独立启动模式（可选）
如果您希望在不同窗口或不同机器分别运行协议端和大脑：
1. **先启动协议端**：双击 `NapCat.Shell.Windows.Node/napcat.bat` 保持在线；
2. **再启动 QQ 大脑**：在终端执行：
   ```bash
   python run_qq.py
   ```

## 六、核心技能与互动玩法实测

### 1. 私聊与群聊唤醒测试
- **私聊直接发**：发任意消息（如“你好”），机器人立即回复；
- **群聊双唤醒机制**：
  1. **唤醒词触发**：在群消息中直接包含 `鱼鱼` 或 `小金鱼`（如：“`鱼鱼，在吗？`”），机器人识别到唤醒词会立即应答，并开启 120 秒连续对话窗口；
  2. **@ 触发**：在群里 `@机器人` 同样立即触发回复；
  3. **主人特权**：在 `owner_qqs` 名单中的主人发话，机器人自动识别身份并优先响应。

### 2. 情绪动力学（PAD 空间与阻尼动量）
大脑内置连续 PAD 情感模型与阻尼惯性公式（数据保存在 `skills/im/qq/data/emotions.json`）：
- **夸奖/宠溺**：好感度（Affection）与愉悦度（Valence）快速攀升，主导心境进入 `sweet`（甜蜜撒娇）；
- **批评/挑衅**：因情绪动量阻尼，不会机械突变变脸，而是表现出微嗔、小傲娇、嘴硬（“哼，我才不笨呢”）；若持续受到攻击则逐步触发委屈或生气反驳；
- **关怀倾听**：主人倾诉烦恼时，主动降低活泼度，以安静温和的态度倾听安慰。

### 3. 点歌与音乐卡片分享
- **点歌指令**：
  > “我要听晴天” 或 “点歌 周杰伦 稻香” 或 “来首海阔天空”
- **功能特性**：
  1. 优先搜索 QQ 音乐正版曲库，无缝生成 **QQ 音乐结构化卡片** 投递到聊天窗口；
  2. 卡片发送成功后不再冗余发送文字链接，保持窗口清爽干净；
  3. 若仅输入“点歌”，机器人会体贴引导：“想听什么歌呢？请告诉我歌名哦 🎵”。

### 4. 实时全球天气查询
- **天气指令**：
  > “北京天气” 或 “查一下上海天气怎么样” 或 “明天深圳下雨吗”
- **功能特性**：
  精准获取当前气温、体感温度、阴晴降水、风力风向，并根据气象情况自动生成温馨穿衣与出行提醒。

### 5. 多模态视觉看图理解
- **看图互动**：向机器人发送一张图片（表情包、生活照、风景照等）并附带提问（如“好看吗？”、“这是什么？”）；
- **工作机制**：视觉模型（如 `Qwen/Qwen3.5-4B`）在后端毫秒级生成画面文字描述，大脑结合画面细节给出自然细腻的人格化回复。

## 七、常见问题与排查手册

### Q1: 双击 `start_napcat_windows.bat` 出现闪退？
- **已修复保护机制**：脚本末尾已增加安全 `pause` 拦截，即使发生网络或环境错误，窗口也会驻留并打印完整报错，不会无提示退出；
- **排查步骤**：
  1. 确认 Python 解释器在系统 PATH 环境变量中（输入 `python -V` 能识别）；
  2. 确认 `config.yaml` 格式完好无语法错误。

### Q2: 提示 `OneBot 未连接` 或连接被拒绝？
- **原因**：NapCat 协议端尚未登录成功，或 3001 端口尚未处于就绪状态。
- **解决**：只需使用 `start_napcat_windows.bat` 一键启动，等待手机 QQ 扫码确认完成，底层会自动完成握手与上线通信。

### Q3: 群里发送消息机器人没有反应？
- **排查项**：
  1. 检查是否包含了配置的唤醒词（如“鱼鱼”），或是否 `@` 了机器人；
  2. 检查 `config.yaml` 中 `groups` 白名单设置。若填了群号，则只回复白名单群；若需在所有群响应，请保持 `groups: []` 为空列表。

### Q4: 如何修改机器人的名字或更换大模型？
- **方法 1（推荐）**：直接打开浏览器访问 `http://127.0.0.1:18888`，在 Web 界面中修改并点击保存，热加载即时生效；
- **方法 2**：直接编辑 `config.yaml` 的 `brain:` 与 `qq:` 相应字段，修改后在 Web 后台点击“重启 QQ 服务”即可。
